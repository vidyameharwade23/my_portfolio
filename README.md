## ✨ Features

- **Editorial Design** — Warm studio stone (`#F6F5F2`) theme with coral-orange (`#FF5528`) accents
- **Scroll-Driven Animations** — `useScroll` + `useTransform` powered parallax, image zoom, and depth shifts
- **Continuous Marquee Ticker** — Infinite scrolling skills banner
- **Circular Rotating Stamp Badge** — Rotating `• BCA GRADUATE • DATA ANALYST •` stamp in the Hero
- **Interactive Skills Grid** — Technical, Office Tools, and AI Tools Explored sections
- **Projects Showcase** — 3 projects with scroll-reveal card entrance animations
- **Certificates Grid** — 3 verified learning achievement cards
- **Contact Form** — Direct email/GitHub/LinkedIn contact section
- **Mouse Spotlight Effect** — Subtle ambient radial glow following cursor
- **Custom Scrollbar** — Branded coral-orange accent scrollbar
- **Fully Responsive** — Mobile, tablet & desktop optimized

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org) (v18 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/vidyameharwade23/portfolio.git

# Navigate into the project
cd Vid_portfolio

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Build for Production

```bash
npm run build
```
